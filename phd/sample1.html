Direction 1

Real-Time Clinical Dialogue to MIMIC Translation

Based on Prof. Anne's suggestion and building upon the "S-proto" and "Where does it hurt?" (ECAI) frameworks.

1. Real-Time Capture

Speech recognition running locally on a doctor's MacBook captures the physician-patient dialogue.

2. Live Translation

The system translates SOAP-based dialogue intents into structured MIMIC admission formats instantly.

3. Uncertainty Flagging

Models return responses with calculated uncertainties, highlighting exactly where the physician needs to ask follow-up questions.

The Goal: Create a deployable clinical process improvement tool. A working prototype demonstrating this pipeline would serve as an incredible proof-of-concept before expanding into a full paper.

Direction 2

Robust Predictions in Dynamic Medical Dialogues

Merging Prof. Löser's recent works: "Where does it hurt?" (Intent Trajectories) and "Robust Conformal Prediction for Infrequent Classes" (DGCP).

  • The Challenge

    Medical dialogues often branch into rare diagnoses (the "long tail"). Standard LLMs suffer from miscalibration in these low-data regimes, risking patient safety.

  • The Proposed Solution

    Apply Dynamically Grouped Conformal Prediction (DGCP) to real-time dialogue state tracking. If a conversation shifts towards a rare medical intent, the model dynamically groups it with semantic taxonomies (like ICD-10) to guarantee statistical coverage.

Real-Time Uncertainty Flow

Turn 1-5 (Common): Acute Symptoms
High Confidence / Standard CP
Turn 6-8 (Rare): Niche Objective Exam
Low Data → Trigger DGCP Grouping
System Output:
"I am 90% confident the intent is within [Grouped Diagnosis A, B, C]. Ask question X to narrow down."
Direction 3 (Core Proposal)

Off-Grid & Austere Environment Medical VLMs

Deploying highly-quantized, multi-modal Edge AI for extreme zero-connectivity point-of-care scenarios.

Wilderness/Hiking

Zero internet, urgent trauma relief guidance.

Space Exploration

High-latency/disconnected astronaut medical support.

Conflict Zones

Internet bans (e.g., Ukraine), local civilian triage.

Emergency Transit

Ambulances/runways needing immediate offline intelligence.

The "Why"

Given the current geopolitical climate and the rise of consumer edge hardware, there is a massive gap in fully localized, multi-modal medical AI. Prof. Löser's work proves that robust medical NLP can run on a doctor's MacBook. This project pushes that boundary: running a 1B–3B parameter Vision-Language Model (VLM) natively on consumer mobile devices (Android/Apple via LiteRT) to guide non-professionals through multi-turn, sequential triage and monitoring until professional help arrives.
